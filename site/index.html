f00tils · pure assembly · multicall · MIT · v0.16.3

GNU userland → f00tils

f00tils replaces four GNU packages in one freestanding multicall: coreutils, grep, findutils, and diffutils (115 tools). Pure x86-64 assembly, no libc. Default is modern (theme, chrome, extras). --core is byte-identical to GNU and must win wall + CPU.

Install Benchmarks Scoreboard

Product laws

  1. Clone first. Under --core, output is byte-identical to the GNU tool.
  2. Win on resources. --core must beat GNU wall time and CPU.
  3. Modern is amazing. Default mode is themed chrome + extras — not a pale GNU subset.
  4. One binary. Multicall by argv0 across four GNU package sets.

Install

Default install: multicall f00 + every f00-* for the full tool list (coreutils + grep + findutils + diffutils + hub extras) + bare names (ls, grep, find, diff, …) so PATH supersedes GNU. Not a hand-picked subset — F00_TOOLS=all is the default.

One-liner

$ curl -fsSL https://f00.sh/install.sh | bash
EnvEffect
INSTALL_DIRBin dir (default ~/.local/bin)
F00_VERSIONRelease tag (default: latest)
F00_LOCALLocal asm/ with ./f00
F00_TOOLSall (default) or comma list
F00_SUPERSEDE=1Default: bare names for every installed tool
F00_SUPERSEDE=0Only f00 + f00-* (side-by-side)
F00_ALIAS=1Optional shell aliases (usually unnecessary with supersede)
F00_MAN=1Install man pages (default on)
 
# pin version
curl -fsSL https://f00.sh/install.sh | F00_VERSION=v0.16.3 bash

# local build
curl -fsSL https://f00.sh/install.sh | F00_LOCAL=$PWD/asm bash

# f00-* only (keep GNU bare names)
curl -fsSL https://f00.sh/install.sh | F00_SUPERSEDE=0 bash

# later: turn PATH replace off without reinstall
f00-config replace off
