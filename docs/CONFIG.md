# Config

Use the product:

```bash
f00              # TUI
f00-config       # CLI
f00-config show
f00-config replace status
```

XDG tree: `~/.config/f00` (config + themes).  
Install seed and toggles: `replace = true|false`, `f00-config theme list|set|pick`.
